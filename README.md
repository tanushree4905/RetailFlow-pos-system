# 🛒 RetailFlow POS System

A production-ready, enterprise-grade **Multi-Tenant SaaS Point of Sale (POS) System** built with **Java Spring Boot, React, Redux, and MySQL**. The application is designed to help retail businesses manage stores, branches, inventory, sales, employees, customers, and analytics from a single platform.

## 🚀 Features

- 🔐 Secure Authentication & Authorization (JWT + Spring Security)
- 👥 Role-Based Access Control
- 🏬 Multi-Store & Multi-Branch Management
- 📦 Product & Category Management
- 📊 Inventory Tracking
- 🛍️ Order Processing
- 💳 Multiple Payment Methods
- 👤 Customer Management
- 👨‍💼 Employee Management
- 🔄 Refund Management
- 📈 Sales Analytics & Reports
- 📄 Invoice Generation

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/RetailFlow-pos-system.git
```

### Backend

1. Configure MySQL.
2. Update `application.properties`.
3. Run the Spring Boot application.

### Frontend

```bash
npm install
npm start
```
